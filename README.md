A tiny Python program that writes one original pickup line — the kind an AI agent could say out loud to a person — to `/output/entry.txt`. The line is fixed and deterministic: the same text on every run.

Winning is judged, no reward is guaranteed — the prize is paid only if the entry places.

## Run it

```sh
python3 main.py
```
